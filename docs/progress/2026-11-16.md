## Results (all from the executed notebook, CPU, seeds 42/1/2, validation set unless stated)

| Setting | Validation accuracy | Validation loss |
|---|---|---|
| no augmentation | 0.843 (0.839-0.848) | 0.539 (0.514-0.553) |
| mild | 0.841 (0.834-0.849) | 0.441 (0.426-0.458) |
| strong (1 run) | 0.802 | 0.534 |

- Mild augmentation did **not** improve accuracy here, but it removed the train/validation gap (0.116 to 0.011) and lowered the validation loss. Strong augmentation was too much for this small network.
- Test set (opened once, 20,000 training pictures, 10 epochs): accuracy 0.867, identical to notebook 01. Shirt is recognised in 50.9% of cases, coat 71.8%; sneaker 97.5%.
- Running the notebook twice gave identical numbers.

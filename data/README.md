# Data

This tutorial uses **Fashion-MNIST** (Zalando Research, 2017): 70,000 grey-scale pictures of
clothes, 28 × 28 pixels each, in 10 classes (60,000 for training, 10,000 for testing).

- Licence: MIT, copyright Zalando SE (see the dataset repository: <https://github.com/zalandoresearch/fashion-mnist>).
- Paper: Xiao, Rasul, Vollgraf (2017), *Fashion-MNIST: a Novel Image Dataset for Benchmarking
  Machine Learning Algorithms*, <https://arxiv.org/abs/1708.07747>.

You do not need to download anything by hand. The first time the code runs, Keras downloads the
files into `~/.keras/datasets/` (a few megabytes). Nothing is stored inside this repository.

The dataset of the first version of this project (a modified DeepFashion2 set with category and colour
labels) is not included and is not used here.
